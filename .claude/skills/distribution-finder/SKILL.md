# Distribution Finder — 국내외 유통 판매처 현황 및 가이드 스킬

CoBTS 서비스 1단계에서 원두 판매처 연동 전략과 현재 상태(보류) 및 플랫폼별 기술/법적 검토 사항을 정의합니다.

> **현재 공식 상태**: **연결 보류 (Pending)**  
> *이유: 네이버 쇼핑 API HUB 이관 절차 확인, 아마존 Creators API 자격 요건 검토, 공정위 추천·보증 심사지침 등 법적·운영 검토가 진행 중이며, 1단계에서는 사용자 편의를 위한 '검색 다이렉트 딥링크' 및 대표 스페셜티 샵 정보만 안내 형태로 제공.*

---

## 1. 플랫폼별 연동 현황 분석

| 플랫폼 | 연동 방식 | 기술 상태 | 법적/운영 고려사항 |
|---|---|---|---|
| **네이버 쇼핑 (Naver Shopping)** | 검색 API (`v1/search/shop.json`) | NAVER Developers → NAVER API HUB 이관 진행 중. 발급 절차 확인 필요 | 국내 원두 구매 접근성 최고. 스마트스토어 및 공식몰 연동 |
| **아마존 (Amazon Global)** | Creators API (구 PA-API) | **PA-API 5.0은 2026년 4월 30일 공식 종료**. 신규 Creators API는 최근 30일 적격 판매 10건 이상 실적 요구 | 한국 마켓플레이스 직배송 포함 여부 및 계정 유지 요건 확인 필요 |
| **구글 쇼핑 (Google Shopping)** | 소비자 검색 링크 (Deep Link) | 일반 공개 소비자 검색 API 부재. 쿼리 URL 구조(`tbm=shop`) 활용 | 글로벌 스페셜티 로스터리(블루보틀, 스텀프타운 등) 상품 비교 |

## 2. 공정위 제휴 표시 및 법적 가이드라인 (사전 준수)

- **공정거래위원회 추천·보증 등에 관한 표시·광고 심사지침**:
  - 향후 제휴 수익(커미션) 연계 시 게시물 제목 또는 첫 부분에 "제휴 마케팅 수수료를 제공받을 수 있음"을 명확히 표시
  - **추천 알고리즘 중립성**: 판매 수수료율과 추천 순위를 엄격히 분리(A안 권장)하여 맛 이론 계산값에 의한 추천의 객관성을 보장
- **원산지 표기 주의**:
  - 생두 생산국(Country of Origin)과 원두 가공국(Country of Roasting)을 명확히 구분하여 표기
